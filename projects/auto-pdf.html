Overview

Developed an Excel and Python automation workflow that generated large volumes of HR documentation while reducing repetitive data entry and maintaining quality control checks.

Problem

PThe project I was working on had nearly 1,000 employees, and as construction neared completion, the administration team needed to prepare individual layoff forms for everyone. Although many fields in the PDF were identical, such as job site and company details, each PDF still had to be manually filled out. Producing hundreds of nearly identical documents meant hours of repetitive data entry and increased the chance of errors.

Upon seeing how repetitive this process was, I looked for a way to reduce manual work while still maintaining final human review.

After I created an internal automation tool to save time, it was demonstrated to senior management, who then requested the same approach for other admin and HR forms used in other projects.

My Role

I used the layoff PDF form and, with Excel and Python, built an automated tool that generates completed forms from a single workbook.

More than just automating the process, I also focused on making the tool practical for everyone to use. My goal was to create something that the admins with little or no programming experience could use confidently.

Solution

To build an Excel user interface for data entry, while Python worked in the background to use that information to generate each PDF.

My workflow allowed administrators to:

  • Use searchable drop-down lists for easier employee selection
  • Automatically produce the employee’s ID and last day on site based on the selected employee
  • I created checkboxes for easier selection of termination reason
  • Added optional comments, if needed
  • After saving the workbook, you could then generate all the needed PDFs with a single double-click

The design also focused just as much on reliability as it did automation, though. To help try to reduce errors as well as make the tool also accessible to non-technical staff, I:

  • Wrote a step-by-step user guide to help first-time users learn the process, screenshots included
  • Protected all the formula cells to prevent accidental changes
  • Added built-in validation and error messages to help catch some common user mistakes
  • Added a “manual check” for specific situations needing it
  • Implemented a one-click launcher so admins could run the program without needing to open the command box to run the code

One thing I chose not to automate was adding the admin’s name and signature to ensure each PDF was opened and verified before being processed. It created a final “quality control” check and added accountability to the admin.

Result

The final product replaced a repetitive, multi-step document preparation process with a workflow that required far less user input before generating the forms with a single double-click.

This original project was then expanded into three more separate automation tools:

  • Payroll Issue Resolution Tool
  • PCN Tool
  • Transfer Notice Tool

After the solution was presented to senior management, they intended to roll it out to other job sites.
